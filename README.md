# UniDepth-LSS
<p align="center">
  <strong>Accepted at the DriveX Workshop, ECCV 2026</strong>
</p>

UniDepth-LSS is a camera-only Bird’s-Eye-View (BEV) vehicle segmentation framework that integrates frozen metric depth priors from **UniDepthV2** into the geometric projection pipeline of **Lift-Splat-Shoot (LSS)**.

Unlike conventional LSS, which learns a discrete depth distribution using only BEV supervision, UniDepth-LSS uses metric depth predicted by a pretrained depth foundation model to guide the lifting of image features into 3D space. Features from the six surrounding cameras are projected into a shared ego-vehicle coordinate frame, aggregated into a BEV representation, refined using a lightweight transformer, and processed by a segmentation head.

The UniDepthV2 backbone remains frozen during training, while only the feature-projection, BEV-refinement, and segmentation components are trained. The method is evaluated on camera-only BEV vehicle segmentation using the nuScenes dataset.

## Acknowledgements

This work builds upon ideas and implementations from the following repositories:

- [Lift-Splat-Shoot](https://github.com/nv-tlabs/lift-splat-shoot), which provides the geometric framework for lifting multi-camera image features into 3D space and aggregating them into a shared BEV representation.
- [UniDepth](https://github.com/lpiccinelli-eth/UniDepth), which provides the pretrained UniDepthV2 metric depth foundation model used for depth and feature extraction.

We thank the authors of both projects for making their research and implementations publicly available.
